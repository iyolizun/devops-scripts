# devops-scripts

A collection of scripts and tools for automating DevOps tasks.

## Prerequisites

* Python 3.8+
* pip

## Installation

```bash
pip install -r requirements.txt
```

## Usage

* Run `main.py` to execute the DevOps tasks.
